插入文本:
  1. 将文本分割成行、换行
  2. 逆序执行插入行、换行
  3. 遇到错误则中断

逆序是可以不用推进插入点. 例如在pos处, 插入 "time\nGet\r\nTime"

分别执行:
  1. Insert(pos, "Time")
  2. NewLine(pos)
  3. Insert(pos, "Get")
  4. NewLine(pos)
  5. Insert(pos, "time")

具体实现时, 可以利用StringView概念

插入行文本(尽量减少CELL生成):
  1. 找到pos所在行与CELL, 并转换到CELL内偏移值
  2. 分成恰好在两个CELL之间和CELL内部
  3. 进行一次弱插入
  4. 若还有文本未插入: 进行一次强分离
  5. 成功: 再进行一次弱插入
  6. 若还有文本未插入: 将剩余文本安长度做成CELL

因为存在中途失败的可能，需要修改自然段长度、总文本长度时，采用每次增加的方式, 而不是最后返回时一次性增加.

弱插入(不生成CELL的情况下尽可能插入文本):
  1. 若在中间插入，则尽可能插入(后优先)
  2. 若在之间插入, 然后则尽可能在当前CELL插入(前优先)
  3. 还有的话, 后面的CELL(存在的话)则是插入(后优先)
  4. 前优先会推进POS/STR, 后优先不会
